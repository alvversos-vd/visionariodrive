# Beta Feedback — Visionário Drive Start v1.0.0

Registro dos primeiros 10 motoristas do Beta Fechado.
**Objetivo:** apenas coletar. Nenhuma sugestão é implementada durante o Release Freeze — ideias novas vão para `docs/architecture/roadmap.md`.

## Como registrar

Cada entrada abaixo deve seguir a estrutura da tabela.

**Prioridade** ∈ {P0, P1, P2, P3, Sugestão}
- **P0** — crash, perda de dados, GPS parado, turno bloqueado → correção permitida no Freeze
- **P1** — fluxo crítico degradado sem workaround → correção permitida no Freeze
- **P2** — incômodo, mas com workaround → registrar, decidir na Sprint 6
- **P3** — cosmético / polimento → roadmap
- **Sugestão** — nova feature → mover para `roadmap.md`
